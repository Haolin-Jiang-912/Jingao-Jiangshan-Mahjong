# 鸡歪麻将厅（江山麻将 · 校园怀旧像素风）

在线游玩：<https://jingao-jiangshan-mahjong.jianghaolin.workers.dev/>

页面和联机房间都托管在 Cloudflare，不用内网穿透，也不用开发者电脑保持开机。任何同学都可以打开网址创建房间。

## 2.1：云端统一牌局与防误触

- 按实物参考还原四张长方形课桌：浅米色桌面、蓝色包边，笔槽在远离座位、朝向中央拼缝的一侧。保持 3:2 比例。
- 大厅区分好友联机和单人练习，两种玩法均可选；昵称记忆、房间号校验和游戏内规则。
- 先选手牌，再点「打出」确认，支持听牌提示；手牌始终单排铺开，竖屏可左右滑动，横屏完整查看。
- 手机使用独立牌桌与底部手牌区域，座位靠桌定位；音乐与上传收进设置。骰子用白底圆点和数字显示，可查看四人定庄结果。
- 修复财神补 789 等顺子的漏判、带吃牌副露时误算碰碰胡、单机抢杠应答卡住、重复开盘旧骰子定时器，以及远端非法吃碰杠响应。
- Cloudflare Durable Objects 提供同源 WebSocket、定向私有手牌分发、90 秒断线回座及房间休眠恢复。

联机版由云端统一发牌、推进回合、处理吃碰杠胡和结算。房主与好友都只操作自己的座位；每条命令绑定当前决策窗口和唯一编号，重复请求只执行一次。云端持久保存牌局及回执，刷新页面可以恢复同一牌局。断线先留 5 秒恢复时间，再由云端 AI 暂代，90 秒内可凭原页面会话回座。

点牌只选中，即使连点也不会直接出牌。点独立「打出」按钮才提交，等待云端确认时锁定后续操作。心跳同步保持选中牌的身份，财神另需确认。拖动、触摸取消、第二根手指及过期回合均有防护。

## Cloudflare 部署（首选）

```sh
npm ci
npx wrangler login
npm run deploy
```

`wrangler.jsonc` 已包含静态资源和 SQLite Durable Object 绑定、迁移；无需另配 WebSocket 地址。`scripts/build-assets.js` 只发布明确列出的游戏素材，不会把源码照片、凭据和测试文件作为网页资源上传。开发调试运行 `npm run dev:cloudflare`。

使用官方支持的 WebSocket Hibernation API，在空闲时休眠；免费方案有配额限制，实际额度以 Cloudflare 控制台为准：
[Cloudflare Durable Objects 文档](https://developers.cloudflare.com/durable-objects/best-practices/websockets/)。

## 两种玩法

详细的测试范围、恢复时限与手机检查结果见 [RELIABILITY.md](RELIABILITY.md)。
- **8盘一局**：固定打 8 盘，按总分排名（特殊分即时计入）。
- **局麻 30 分起底**：每人 30 分，有人归零即散场；特殊分（★）递延到总结算才计入，负分按 0 计。

## 江山麻将核心规则
- **144 张牌**：万条筒各 4 张 ×9、字牌 7 种 ×4、花牌 8 张。花牌不入手：摸到即垫出亮在面前，从牌墙**尾**补牌，每朵花结算 +1 分。
- **骰子定庄**：四人掷骰定庄家，再掷一次决定从哪边牌墙起摸；庄家 14 张，闲家 13 张。
- **财神（百搭）**：翻牌的下一张即财神（数字牌按同花色 1→9 循环，字牌东南西北中发白循环）。财神在手可当任意牌；打出财神有二次确认。
- **只能自摸，不能点炮**；但**可以抢杠**：别人补杠的牌若正好是你听的牌，可抢杠胡，被抢者承包三家分（×3）。
- **吃 / 碰 / 明杠 / 暗杠 / 补杠**齐全，声明优先级 杠 > 碰 > 吃。
- **牌墙剩 20 张流局**，本盘不计分。

## 算分
结算 = （基础分 + 额外分）× 翻倍 + 特殊分

| 类别 | 项目 | 分值 |
|---|---|---|
| 基础 | 平胡 / 碰碰胡 / 对对胡（七对）/ 十三烂 | 2 / 6 / 6 / 6 |
| 额外 | 单吊 / 财吊（听全部牌）/ 杠开 | 各 +2 |
| 翻倍 | 飘财：财吊状态下打出财神 | 每次胡牌 ×2 叠加 |
| 特殊 | 清一色 / 天胡 / 地胡 | 各 +10 |
| 特殊 | 花牌 | 每朵 +1 |

- 清一色额外规矩：**吃碰同一玩家三手以上，不计清一色分**。
- 自摸胡：其余三家各付；抢杠胡：被抢者一家承包 ×3。

## 文件结构
- `index.html` — 封面与模式入口
- `game.html` / `style.css` — 教室场景牌桌界面（黑板、课桌拼桌、围观同学）
- `engine.js` — 胡牌检测（财神百搭回溯算法）、听牌计算、算分
- `app.js` — 行牌流程、吃碰杠仲裁、抢杠、AI 出牌
- `ui.js` — 渲染、动作条、弹窗、像素音效
- `net.js` — 所有座位共用的客户端：命令确认、同编号重试、版本校验、同步与重连
- `server.js` — Node.js 权威房间服务，与 Cloudflare 共用控制器
- `game-core.mjs` — 可序列化的联机规则状态机、响应窗口、AI 与结算
- `room-controller.mjs` — 命令串行化、持久化回执、私有座位视图与断线恢复
- `test-sim.js` — 无头模拟压测（Node 直接运行 `node test-sim.js`，验证 144 张守恒与分数守恒）

## 联机游玩（云端统一牌局）

2.1 改为服务器权威牌局：浏览器不运行第二套联机逻辑，服务器统一执行所有座位的操作。房主也只收到自己的暗牌。Cloudflare 会持久化完整牌局，页面刷新或房主短暂离线不会重新发牌；本地 Node 服务只在进程内保存房间。

### 邀请同学

线上版本的页面和房间服务同源，任何人都无需填写服务器地址：

1. 打开本文开头的在线地址，输入昵称并创建房间。
2. 把房间里的邀请链接发给好友。
3. 好友点开链接自动加入，至少两位同学在线后，房主点「开始游戏」。
4. 空位由云端 AI 补齐，所有同学查看的是同一盘牌。

调试其他服务器时，可在游戏网址添加 `ws=wss%3A%2F%2F你的服务器` 参数。

### 断线自动重连

公网链路偶发抖动不可避免，本版本内置了完整的会话恢复机制：

- 连接失败自动重试，间隔逐渐增加，最长 15 秒；连续 12 秒收不到消息会重新连接并同步。
- 每个玩家入座时获得会话 token（存 `sessionStorage`，刷新页面不丢），断线重连后**保持原座位**继续牌局，不会变成新玩家。
- 掉线后座位保留 90 秒，先留 5 秒恢复时间，再由云端 AI 暂代。房主与其他玩家使用同样的恢复机制。
- 旧连接异常未断开时（僵尸连接），真身带 token 重连会直接接管，不会出现「房主已在别处连接」死锁。

### 本地开发

```bash
npm install
node server.js
```

打开 `http://localhost:3001/`，联机连接自动指向本机，无需额外设置。

### 其他平台

`server.js` 可部署到任何支持 Node.js 持久进程的平台（Railway / Fly.io / 自己 VPS）。环境变量 `PORT` 由平台注入。
前端也可以单独部署到 Vercel（已含 `vercel.json`），但 Vercel 不支持持久 WebSocket，联机仍需 Render 之类的服务器；此时邀请链接会自动带上 `&ws=` 参数指向联机服务器。

### Cloudflare Workers

首选部署说明见文档开头。`cloudflare-worker.js` 和 `wrangler.jsonc` 是可直接部署的实现，页面与 WebSocket 同源。
