# 鸡歪麻将厅（江山麻将 · 校园怀旧像素风）

浏览器直接打开 `index.html` 即可开局，无需服务器。

## 两种玩法
- **8盘一局**：固定打 8 盘，按总分排名（特殊分即时计入）。
- **局麻 30 分起底**：每人 30 分，有人归零即散场；特殊分（★）递延到总结算才计入，负分按 0 计。

## 江山麻将核心规则
- **144 张牌**：万条筒各 4 张 ×9、字牌 7 种 ×4、花牌 8 张。花牌不入手：摸到即垫出亮在面前，从牌墙**尾**补牌，每朵花结算 +1 分。
- **骰子定庄**：四人掷骰定庄家，再掷一次决定从哪边牌墙起摸；庄家 14 张，闲家 13 张。
- **财神（百搭）**：翻牌的下一张即财神（数字牌万→条→筒循环，字牌东南西北中发白循环）。财神在手可当任意牌；打出财神有二次确认。
- **只能自摸，不能点炮**；但**可以抢杠**：别人补杠的牌若正好是你听的牌，可抢杠胡，被抢者承包三家分（×3）。
- **吃 / 碰 / 明杠 / 暗杠 / 补杠**齐全，声明优先级 杠 > 碰 > 吃。
- **牌墙剩 20 张流局**，本盘不计分。

## 算分
结算 = （基础分 + 额外分）× 翻倍 + 特殊分

| 类别 | 项目 | 分值 |
|---|---|---|
| 基础 | 平胡 / 碰碰胡 / 对对胡（七对）/ 十三烂 | 2 / 6 / 6 / 6 |
| 额外 | 单吊 / 财吊（听全部牌）/ 杠开 | 各 +2 |
| 翻倍 | 飘财：财吊状态下打出财神 | 每次胡牌 ×2 叠加 |
| 特殊 | 清一色 / 天胡 / 地胡 | 各 +10 |
| 特殊 | 花牌 | 每朵 +1 |

- 清一色额外规矩：**吃碰同一玩家三手以上，不计清一色分**。
- 自摸胡：其余三家各付；抢杠胡：被抢者一家承包 ×3。

## 文件结构
- `index.html` — 封面与模式入口
- `game.html` / `style.css` — 教室场景牌桌界面（黑板、课桌拼桌、围观同学）
- `engine.js` — 胡牌检测（财神百搭回溯算法）、听牌计算、算分
- `app.js` — 行牌流程、吃碰杠仲裁、抢杠、AI 出牌
- `ui.js` — 渲染、动作条、弹窗、像素音效
- `net.js` — WebSocket 联机客户端（连接 `server.js` 中继）
- `server.js` — Node.js WebSocket 联机中继服务器（房间管理 + 消息转发）
- `test-sim.js` — 无头模拟压测（Node 直接运行 `node test-sim.js`，验证 144 张守恒与分数守恒）

## 联机游玩（WebSocket 服务器中转）

由于浏览器 P2P 在复杂网络（校园网 / 移动数据 / 对称 NAT）下很难穿透，本版本改用 **WebSocket 服务器中转**。游戏逻辑仍由“房主”浏览器权威执行，服务器只负责转发消息，因此无需担心服务器作弊问题。

封面提供三种一键配置：

- **本机**：服务器地址自动设为 `ws://localhost:3001`，适合同一台电脑开多个浏览器测试。
- **局域网**：服务器地址自动设为 `ws://当前页面主机名:3001`。只要通过 `http://电脑内网IP:3001/` 打开页面，好友同 Wi-Fi 下即可加入。
- **异地**：填写已部署的公网服务器地址（如 Render/VPS），一键生成邀请链接，好友无需部署即可加入。

### 本地联机步骤

1. 启动联机服务器：
   ```bash
   node server.js
   ```
   默认端口 `3001`，`server.js` 同时提供静态页面，打开 `http://localhost:3001/` 即可。
2. 在封面选「本机」或「局域网」，输入昵称，点击对应的开房间按钮。
3. 把弹窗里的邀请链接发给好友。
4. 好友打开链接后自动加入；人满或 1 人以上房主点「开始游戏」。

### 部署到公网

#### Vercel（静态前端）

项目已包含 `vercel.json`，直接导入 GitHub 仓库即可自动部署前端页面。

> 注意：Vercel Serverless Function 不支持持久 WebSocket，因此**联机服务器请用 Render / Railway / 自建 VPS**。

#### Render（联机服务器）

项目已包含 `render.yaml`，在 Render Dashboard 选择「Blueprint」导入仓库即可：
- 服务名：`jw-mahjong-hall-server`
- 构建命令：`npm install`
- 启动命令：`node server.js`
- 免费实例会在 15 分钟无流量后休眠，首次连接可能需等待 30~60 秒唤醒。

部署成功后得到类似 `wss://jw-mahjong-hall-server.onrender.com` 的地址，填到封面「异地」输入框即可。

#### 其他平台

`server.js` 可部署到任何支持 Node.js 持久进程的平台（Railway / Fly.io / 自己 VPS）。环境变量 `PORT` 由平台注入。

### PartyKit / Cloudflare Workers 兼容

如果希望使用 Cloudflare 的实时服务，可参考 `cloudflare-worker.js` 中的 Durable Object 实现，逻辑与 `server.js` 相同：房间管理 + 消息转发。
